## 连接原因与处理

本机 `.env` 中四家密钥均经真实调用验证有效（密钥只保存在本机忽略文件里，未进入版本库）。
Python 自动读取 macOS 系统代理 `127.0.0.1:7897`，通义与智谱在这条代理路径上出现 TLS 提前断开（`UNEXPECTED_EOF_WHILE_READING`）；同一密钥直连成功。

已增加 `API_NO_PROXY` 配置，并在本机 `.env` 中仅为 `dashscope.aliyuncs.com,open.bigmodel.cn` 启用直连。保留其他代理与已有排除项，不关闭证书校验，不更换密钥，不修改系统代理。

实际模型调用通过：`qwen-plus`、`qwen-max`、`qwen3-vl-plus`、`qwen-flash`、`deepseek-chat`、`glm-4-plus`；Tavily 搜索与 `text-embedding-v4` 的 1024 维向量接口也通过。

## 联调修正

- 岗位要求涉及多段材料时，支持多个独立引文并逐条检查，避免拼接引文导致所有匹配被误降为待确认。依据被剔除时，同步修正分析摘要。
- 差距清单允许独立评审纠正已有能力的误判。词面校验未命中不再直接等同于用户缺乏能力；无依据技能仍从草稿技能中移除。
- 实测发现评审可能将时间重叠或缺少 JD 技能判为严重事实问题。现要求高风险意见提供原材料与草稿的差异引文；没有可核对差异的意见保留为待确认建议。技能、单位、项目及数字守卫独立执行；扩大数量等事实改写仍阻止导出。

这份测试简历的教育与工作时间有重叠，最终保留为人工核对事项，没有替用户调整日期。引文和规则检查不等于独立验证经历真实性，单份简历的冒烟测试也不代表所有输入均无问题。

自动化结果：60 项后端测试通过，Ruff 检查、前端 TypeScript 检查与生产构建通过，`git diff --check` 通过。最终评审校验另经真实模型调用及 DOCX 下载复测。
